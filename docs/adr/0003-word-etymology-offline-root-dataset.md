# 词源/词族:本地 MIT 词根数据集承载「词根→词族」,句中构词仍走 LLM

给重点词加「词源分析及扩展」时,词根→词族的映射用打包进 APK 的离线数据集(ECDICT `wordroot.txt`,MIT)加载为内存索引,零 LLM 成本、全 App 一致;而目标词**自身**在句中的构词拆解(如 sneak+ing)继续由现有 LLM `affix` 提供。词根库与词源入口只收录 `class=词根` 的语义核心条目,前后缀仅在词族拆解中作为构件出现。二者分工由数据的确定性决定:词族是"稳定映射表",不是语境释义。

## Status

accepted

## Context

- 参考图以拉丁词根 port(=carry)为锚点列整个词族(export/import/transport/portable/support/report/comport/comportment/deportment),每词拆成 前缀+词根+后缀,"扩展"= 同根词列表。
- 现状 Readlet 已有 `CardWord.affix`(v7):重点词**自身**构词拆解,LLM 生成,JSON `[part,type,meaning]`,详情页/复习页淡蓝「构词」渲染。缺范式:①词根作为可跨词共享的锚点;②同根词族聚合。
- 词族本质是稳定映射,靠 LLM 逐句枚举会漂移(同词跨句给不同/缺词族)、token 暴涨、有编造风险;也正因此不适合作为"语境释义"式的 LLM 产物。

## Decision

1. **本地数据集 = ECDICT `wordroot.txt`**(`skywind3000/ECDICT`,MIT):~1,400 词根/前缀/后缀条目,每条目含 `class`(词根/前缀/后缀)、`meaning`(构词含义)、`origin`(拉丁/希腊/古英)、`example[]`(示例词)。一次构建出两个索引:`word→root`(对 example[] 反向)+`root→family`(example[])。单文件 ~1MB,可裁剪;按现有 `WordLevels` 同款资产管线启动时加载进 `HashMap`。
2. **分工/源可信分层**:语境释义(meaning_in_context/译文/要点/语法/搭配)只能由 LLM 提供;静态事实字段——音标/词性/级别/原型用本地 `word_levels.tsv`,词根/词缀/词源/词族用本地 `wordroot.txt`——**本地可信数据优先**,LLM 仅在本地无数据时兜底,且字段"不确定→null,禁止编造"。词根页的全部拆解/含义/来源取 `wordroot.txt` 原文,不掺 LLM,避免两处打架。
3. **词根页 = 全屏覆盖页**(类比词频详情),复用既有覆盖页 BackHandler 规则;两个入口:①重点词词元信息行(详情页+复习页共用 `WordInfoRow`)的「词源」入口;②统计页「词根库」`>` 入口的分页列表行。`BackHandler` 栈叠加在 词频详情/卡片详情 之上。
4. **词根库(统计页 `>` 入口)**:全屏分页列表,收录**仅 `class=词根`** 条目;按**词族规模降序**(高产生词根优先);行=词根·含义·来源(拉丁/希腊/古英)·词族规模(N 词);顶部搜索框按词根/含义过滤;无限滚动,页大小 30。
5. **词族联动词库**:词族成员若命中用户词库(按 word 或 lemma),标"你见过 N 次",可点进词频详情/一键加练;复用 `cardword GROUP BY word` 词频聚合,零新增表。
6. **诚实策略**:只对有明确词根的派生词(单个词、命中 wordroot 反向索引)显示词源入口;无法确定一律缺省、不编造;词族标注"常见同根词"。词族=有限词典覆盖,不追求穷尽。
7. **高频难点词改造**:统计页原内联前 10 改为纯"高频难点词 ›"`>` 入口行 + 总数;点进(与词根库同款)全屏分页列表(全部难点词,按出现频率降序,无限滚动页大小 30),每词行进词频详情。
8. **无 Room 表变更**:词根数据是静态词典,走资产管线,不进数据库;不 bump `AppDatabase.version`。功能按 AGENTS 规范走 minor 版本升级 + versionCode+1 + 打 release 包。
9. **不编造(全局不变量)**:所有对外展示的词根/词缀/音标/词性/级别/词源等信息必须可溯源(本地词表/词根数据集,或经约束的 LLM 输出);无法确定→缺省/隐藏,绝不编造。现有 prompt"phonetic_uk/us 必须提供、不确定时填最常见、禁止留空"与"不编造"**直接冲突**,改为"本地词表无数据且不确定→null"。
10. **排除专有名词**:analysis prompt 新增规则——人名/地名/建筑物名/机构名/品牌名/书名等专有名词不作为 keyword 重点词(无法给出可靠词根/词性/考点,强行分析即"镜像分析");句子仍正常翻译,要点/语法/搭配照常;专名里的普通词成分(White House→house)单独挑出为普通词。

## Considered Options

- **纯 LLM 每卡生成词根+词族**:零外置数据,但每次分析 token 暴涨、逐句漂移、编造风险、词族覆盖随模型;排除为主方案,仅当无可用数据集时作为瘦身 fallback。
- **EtymOnline 衍生源**(etymoloink、generated-english-roots-list 等):数据多源自 etymonline(Douglas Harper),CC BY-SA/无许可证,**不可打包再分发**,排除。
- **droher/etymology-db**:4.2M 边词源图,数据 CC BY-SA 3.0 传染,排除。
- **WordNet**:许可宽松,但只给派生态,无 etymon 字段,仅作词族覆盖的 optional 补充。
- **词根库收录全部(词根+前后缀)**:前后缀无动词族,单列会稀释"词根"语义并压低列表质量,排除(仅取 class=词根)。
- **词源入口对"LLM 有构词但本地未命中"的词也显示**:回到"词根由 LLM 定义"的漂移老问题,排除;词根锚点只信本地数据集。
- **静态事实字段维持 LLM 优先(仅加"不确定→null"约束)/音标 LLM 优先而词根本地**:覆盖广(生僻词也能出音标),但 LLM 仍留臆造面,与"全不编造"目标不符;排除,取本地可信源优先(A)。
- **词族词放喇叭发音**:「发音条目」术语已限定卡片重点词+搭配短语,纳入会扩术语,排除(v1 词根页不发音)。

## Update (v0.8.0)

本决策在 v0.8.0 做了**部分反转**：词根页/词源展示改为 **LLM 生成 + 持久化**（新增 `root_etymology` 词源库、`lexicon` 支持库，Room v8），本地 `wordroot.txt` 由主数据源**降级为回退/**兜底（离线/失败时）。
- **动机**：本地数据缺逐词拆解覆盖（comportment/deportation）、无中文短义、无推导义、生僻词（disport）无词义——用户要求参考图全格式（中文短义 + `X → Y` 推导义），本地数据无法满足。
- **保留**：①词源触发仍以本地 `word→root` 判定（只在"新词根首次出现"时生成，不是每词都调 LLM）；②诚实 prompt（"不确定→缺省，禁止编造"）；③词源库幂等（已缓存复用）、异步挂载分析不阻塞；④本地拆解/同根作回退。
- 因此"词根锚点只信本地数据集 / 词根页全部取 wordroot 原文不掺 LLM"两条被**修订**：词根页主视图取 LLM 词源库，本地数据作回退。

## Consequences

- APK 增重 = wordroot.txt 裁剪体积(数百 KB 级),离线可用。
- 词根库覆盖受数据集限制(仅 class=词根,~1,400 中过滤;每词根 example[] 有限),诚实标注"常见同根词";未来需更大覆盖再评估许可干净的词源图,不碰 CC BY-SA。
- 统计页新增两个 `>` 入口(高频难点词、词根库)+ 两个分页列表页 + 词根页新覆盖页;导航栈与 BackHandler 优先级需扩展。
- 静态事实字段转为本地可信源优先:生僻词(本地词表未收录)可能缺音标/词性/构词,以"诚实缺省"而非 LLM 臆造呈现;prompt 相应放宽"必须提供读音"约束。
- analysis prompt 改动:①新增专有名词排除规则;②音标/词性等"不确定→null 禁止编造"。需同步 `AnalysisParser`/`AnalysisParserTest` 与新字段规则。
- 「词根」与「词根词缀」(affix)在术语上明确区分,已入 `CONTEXT.md`「内容单元」节;新增「词根库」「高频难点词」术语。
